## Featured Projects

### SIR-Patient
Individual project developed during an internship at CHU Hassan II Fès. The
application processes symptoms described in French and provides a
hospital-orientation recommendation based on the implemented classification and
ranking pipeline.

- NLP classification of symptoms into 9 medical services (TF-IDF + linear SVM)
- Multi-criteria hospital ranking (SAW method) with automatic weighting by Shannon entropy
- Road distance via OSRM and waiting time per service
- Geolocation with a self-hosted Nominatim instance
- PDF appointment voucher with QR code
- Python · FastAPI · scikit-learn · spaCy · PostgreSQL · OSRM · Nominatim · Docker

Source code and data are not publicly available because the project was
developed in a hospital context.

### [Spam Detection ML](https://github.com/x-khalid-x/spam-detection-ml)
Team project. SMS spam classifier with an NLP pipeline (cleaning, stopwords,
stemming, TF-IDF unigrams and bigrams). Several models were compared; logistic
regression reaches 96.68% accuracy on the SMS Spam Collection dataset with a
stratified 80/20 split. Includes a Streamlit application.

- Python · scikit-learn · NLTK · Pandas · Streamlit
- [Live demo](https://spam-detection-ml-wy7s2z2w4ycbxbvxtnwwvb.streamlit.app) · [Source code](https://github.com/x-khalid-x/spam-detection-ml)
